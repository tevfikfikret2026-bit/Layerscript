# LayerScript (`.lys`) 🚀

A minimalist, web-centric programming language that transpiles directly to clean JavaScript.

## 🛠️ Key Features

- **Transpiles to Native JavaScript:** LayerScript code is converted directly into production-ready JS, requiring zero heavy runtimes or virtual machines in the browser.
- **Web-Native Design:** Built from the ground up to interact seamlessly with HTML5 layers, CSS3 styling, and modern browser environment APIs.
- **TypeScript Core:** The compiler pipeline (Lexer, Parser, Compiler) is built using TypeScript to ensure maximum stability and strong type-safety during development.
- **Minimalist & Clean Syntax:** Designed to eliminate boilerplate code, making web logic easier to write, read, and maintain.
